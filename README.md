# Telco Project

## Overview
This project focuses on setting up a basic telecommunications network environment in Linux and testing its connectivity and performance.

## Objectives
- Set up the network and configure routing.
- Connect a client to an application server.
- Test network connectivity.
- Monitor traffic and measure network performance.

## Technologies
- Linux
- Docker
- Nginx
- Network namespaces
- tcpdump
- Wireshark / tshark

## Testing
Connectivity and network performance are tested under different conditions, including normal operation and simulated network problems.

## Results
The network setup and initial tests have been completed. Further documentation and analysis will be added.

## Conclusion
The project provides practical experience with network configuration, traffic monitoring, and performance testing.
